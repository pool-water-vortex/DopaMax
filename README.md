# DopaMax

60秒耐久の脳汁アーケード。光る玉を叩いてコンボを繋げ、倍率を跳ね上げ、FEVERで脳を焼くブラウザゲーム。

`index.html` をブラウザで開くだけで遊べます。依存ライブラリなし、音は全部 Web Audio で合成しています。

## 遊び方

- 玉をタップ / クリックで破壊。連続で叩くとコンボと倍率(5コンボごとに +1)が上がる。
- 叩くたびに効果音の音程が上がる。コンボが切れると音程もリセット。
- 玉の周りのリングが消える前に叩け。逃すとコンボが切れる。残り18%以内で救うと「ギリギリ!!」で1.5倍。
- 12%でクリティカル(3倍)。★の玉は JACKPOT(10倍)。
- 10コンボ以上で衝撃波が発生し、近くの玉をチェーンで巻き込む(連鎖は2段まで)。
- FEVER ゲージが満タンになると8秒間の FEVER。全部2倍、コンボ無敵、玉が増える。
- ラスト10秒は玉が速くなる。終了後はスコアのカウントアップとランク判定(D〜SSS)。

ベストスコアはブラウザの localStorage に保存されます。

## 操作

| 操作 | 動作 |
| --- | --- |
| タップ / クリック | 玉を破壊 |
| Space / Enter | ゲーム開始・リトライ |
| M | ミュート切り替え |
